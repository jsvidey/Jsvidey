Konfigurasi ad slots

Atur jeda iklan berdasarkan detik pemutaran video.

Masukkan URL dari penyedia iklan tepercaya. Jangan menyisipkan script bebas dari sumber tak dikenal.

Cara kerja

Panel ini menyimpan pengaturan slot iklan.

  • Pre-roll: slot sebelum konten dimulai.
  • Mid-roll: titik pemicu pada detik yang ditentukan.
  • Player perlu diintegrasikan agar membaca slot dan memanggil ad SDK / VAST provider.
  • Pengaturan ini sendiri tidak menghasilkan iklan atau pendapatan tanpa jaringan iklan aktif.

Backblaze B2 & storage

Atur batas upload aplikasi dan kuota platform. Kredensial B2 tetap berada di server.

Backblaze B2 object storage

Limit per file dan kuota aplikasi bisa lebih besar dari 20 MB. Kapasitas riil tetap mengikuti bucket dan paket B2 kamu.

Keamanan B2

Jangan simpan Application Key di browser atau database publik.

Kredensial server-side

Kelola B2_ENDPOINT, B2_KEY_ID, dan B2_APPLICATION_KEY melalui Supabase Edge Function Secrets.

Server enforcement

Nilai limit harus dipakai oleh Edge Function create-b2-upload-url. Lihat README admin untuk deployment.
